# UniSideGame

Unity와 C#을 학습하며 제작한 간단한 2D 횡스크롤 게임 프로젝트입니다.

플레이어 이동과 점프, 적과 포탄, 제한시간, 게임오버 및 스테이지 클리어 등 기본적인 2D 게임 기능을 구현했습니다.

## 개발 환경

- Unity 2022.3.7f1
- C#

## 주요 기능

- 플레이어 좌우 이동 및 점프
- 플레이어 애니메이션 처리
- 적 캐릭터 이동
- 일정 시간마다 포탄 발사
- 포탄 충돌을 통한 플레이어 사망 처리
- 제한시간 관리
- 게임오버 및 스테이지 클리어
- 플레이어를 따라가는 카메라
- 스테이지 이동 및 재시작

## Scripts

### PlayerController.cs
플레이어의 이동과 점프를 처리하고 상태에 따라 애니메이션을 변경합니다.  
적이나 위험 요소와 충돌하면 게임오버 상태로 전환하며, Goal에 도착하면 스테이지를 클리어합니다.

### EnemyMove.cs
적 캐릭터를 이동시키고 이동 구간의 끝에 도달하면 방향을 변경합니다.

### CanonShout.cs
일정한 시간 간격으로 포탄을 생성합니다.

### ShellMove.cs
생성된 포탄을 이동시키고 플레이어와 충돌하면 플레이어를 사망 처리합니다.

### CameraController.cs
플레이어의 위치를 따라 카메라를 이동시키며 지정된 범위 밖으로 이동하지 않도록 제한합니다.

### TimeController.cs
게임의 제한시간을 계산하고 현재 남은 시간을 관리합니다.

### GameManager.cs
게임오버와 스테이지 클리어 상태를 확인하고 관련 UI와 제한시간을 관리합니다.

### SceneContoller.cs
다른 스테이지로 이동하거나 현재 스테이지를 다시 시작하는 기능을 처리합니다.
